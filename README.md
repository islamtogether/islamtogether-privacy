# Islam Together — Política de Privacidad (Privacy Policy)

Repositorio estático listo para **GitHub Pages** con la **Política de Privacidad** oficial de la aplicación **Islam Together** (`com.islamtogether.app`), requerida por **Google Play Console**.

---

## 🚀 Cómo publicarlo en GitHub Pages

1. Crea un nuevo repositorio público en GitHub llamado, por ejemplo, `islamtogether-privacy`.
2. Desde una terminal dentro de esta carpeta (`islamtogether-privacy`), ejecuta:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Privacy Policy for Google Play"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/islamtogether-privacy.git
   git push -u origin main
   ```
3. En GitHub, entra en **Settings → Pages**.
4. En **Build and deployment → Source**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
5. En 1 minuto tendrás tu URL pública lista:
   `https://TU_USUARIO.github.io/islamtogether-privacy/`

---

## 📍 Dónde pegar esta URL en Google Play Console

- **Contenido de la aplicación (App content) → Política de privacidad (Privacy policy):** Pega la URL de este GitHub Pages.
